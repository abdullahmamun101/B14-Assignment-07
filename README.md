Project name: (বাজার দর / BazarDor)

Description:
A web application for viewing daily prices of essential commodities in Bangladesh, tracking price increases and decreases, and comparing prices across different markets.

Technologies Used:
Next.js
TypeScript
React
Tailwind CSS
Better Auth
REST API
react-hot-toast

Features:
View daily prices of essential commodities
Browse products by category
View lists of products with rising and falling prices
View detailed product information and market-wise prices
Sort products from lowest to highest price and highest to lowest price
Sign up and sign in using email and password
Social login with Google and GitHub
View and update user profile information
Responsive design for different screen sizes
Loading skeletons, toast notifications, and a custom 404 page
